# Security Policy

## Supported versions

This is a static portfolio site. The latest version on the default branch is the only supported version.

## Reporting a vulnerability

Please do not open a public issue for a suspected credential leak or other sensitive security problem.

Instead, contact the project owner privately at **v1912223@gmail.com** with:

- A short description of the issue
- The affected file or URL
- Steps to reproduce the problem
- Any suggested mitigation

Please allow reasonable time for a response and remediation before public disclosure.

## Before publishing

- Search for API keys, access tokens, passwords, private keys, and `.env` files.
- Remove personal information that should not be public.
- Confirm that third-party links and downloads are intentional.
- Review the final Git diff before pushing.
