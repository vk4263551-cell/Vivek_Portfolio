## The idea

This site is a compact personal portfolio for **Vivek Kumar**, a data science student at Galgotias University. It brings together an introduction, technical skills, resume content, project work, and contact details in a lightweight static experience that can be hosted almost anywhere.

The visual system is based on the Editorial theme by [HTML5 UP](https://html5up.net/editorial), customized for a data-focused portfolio.

## Run locally

No build step or package installation is required.

### Option 1: open directly

Open [`index.html`](index.html) in a browser.

### Option 2: use a local server

Using a local server keeps asset loading behavior close to production:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

1. Create or select a GitHub repository.
2. Push this project to the repository's default branch.
3. In **Settings > Pages**, choose **Deploy from a branch**.
4. Select the default branch and the `/ (root)` folder, then save.

GitHub Pages will serve `index.html` as the site entry point.

## Security and privacy

- No API keys, tokens, passwords, or private keys belong in this repository.
- Review personal contact details before making the repository public.
- Keep secrets in environment variables or a secret manager; this static site does not need secrets to run.
- See [`SECURITY.md`](SECURITY.md) for the reporting process and publishing checklist.
